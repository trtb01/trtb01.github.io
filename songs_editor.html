songs_editor

append new songs to songs.json with help from any ai chatbot. read the collapsible below first.

how this works (read me first)
  1. below is the ai prompt — hit [copy prompt].
  2. open any ai chatbot (claude, chatgpt, whatever you like).
  3. paste the prompt, then paste your raw list of new songs after it.
  4. the chatbot will return only a json array, formatted exactly for this tool.
  5. paste that json into the paste box below and hit [validate & preview].
  6. the tool fetches the current songs.json from this site, appends your songs, checks for duplicates (duplicates block the download and are listed for you), and shows a numbered preview of the full merged list.
  7. hit [download songs.json], then replace songs.json in your website repo with the downloaded file and publish. done.

notes: songs appear on the site in array order — new songs go on the end, in the order you gave them. there is no "notes" field, ever. if validation fails, the error tells you what the chatbot got wrong — just re-ask it.
