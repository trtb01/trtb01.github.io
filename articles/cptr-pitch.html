open webui computer (cptr) — the pitch for your friend

hi mom!!

here's how i'd sell this to someone who's frustrated that claude code is chained to their laptop. this is everything i found from the knowledge base and the web.

the core problem it solves

right now your friend's claude code workflow is: be at the laptop, run claude, do the thing, walk away, done. if they want to check on a build, push a hotfix, or review an agent's work from literally anywhere else — phone, tablet, borrowed machine, couch, bed, train — they're out of luck. their machine is locked to them physically.

cptr flips that completely. it runs one command on their laptop, and suddenly their whole machine — files, terminal, git, claude code, everything — is served to any browser. their phone. a tablet. another computer. someone else's chromebook. doesn't matter. it's not a stripped-down ide in a tab and it's not a container copy of their repo — it's literally their machine, running on their hardware, at full power, wherever they open it.

how it works (simple version)

pip install cptr
cptr run

that opens http://localhost:8000 in the browser. full workstation. done.

to access from another device:

  • same wi‑fi: cptr run --host 0.0.0.0, then open http://<lan-ip>:8000 on the phone
  • away from home: tailscale (recommended, private mesh), cloudflare tunnel (public url), or ngrok

no cloud tenant. no account on someone else's service. no repo upload. nothing leaves their machine unless they choose to expose it.

why it's perfect for a claude code power user

1. it unlocks their laptop — the exact frustration you're targeting

they can run claude code from their phone. push a hotfix from the train. check on a long-running deploy from bed. ship a side project from the park. sessions persist — close the tab, come back tomorrow on a different device, everything is exactly where they left it. terminal sessions keep running even after disconnect. it genuinely works mobile-first; the ui is built for touch and portrait screens, not a desktop site squeezed into a phone.

2. their existing claude code subscription works natively

this is the key part: you plug claude code in as a native backend inside cptr. no extra api key needed. in settings → admin → agents, you add claude code as a profile (needs claude-agent-sdk pip-installed on the host). it appears in the model selector like any other provider. the conversation runs inside the workspace with full tool access — files, terminal, web search — and sessions resume automatically across devices.

and they're not locked into just claude code. cptr supports codex, claude code, cursor, grok, opencode, cline, gemini, and pi as native backends — all side by side on the same workspace. one session with claude code, next chat with codex, no context-switching.

4. plan mode — because yes, even better approval flow

it has plan mode: before the ai writes a single line, it produces an implementation plan. you review and approve before it starts coding. this works with claude code, codex, or the built-in ai agent — whichever they hook up. that's a huge quality-of-life improvement on its own.

5. it's free

free forever, even at work, even for companies. $0. no account needed, no credit card. supporter seats are $60/year if they want extras, but the core thing is completely free.

6. private by design

it runs on their hardware and talks to nothing unless they configure it to. code never leaves their machine. the ai calls go out to whichever provider they choose (anthropic, openai, local ollama — or nowhere at all). nothing is uploaded to a vendor cloud. treat access like ssh and they're golden.

the bottom line

your friend's current frustration is that their coding agent is stuck at their desk. cptr turns their machine into a server that follows them everywhere. claude code on the phone. full git on the tablet. a terminal session that survives closing the tab and reconnects from any device. every file, every agent, every project — all accessible from any browser, on any screen, without compromising on power or privacy.

one command to install. the subscription they already pay for. their machine, from anywhere. that's the pitch.
